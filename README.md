# dut-postdoc

大连理工大学博士后研究工作的统一入口，按 [Karpathy「LLM Wiki」模式](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 由 AI 辅助维护。

三层架构：

- **Sources 层**：作为事实核验依据的原始资料，AI 只读、不修改。
- **Schema 层**：定义知识库的组织结构、写作约定与 AI 维护流程。
- **Wiki 层**：由 AI 辅助整理、关联并持续维护的研究知识与工作内容。

核心操作：

- **Ingest**：整理新资料，将有效信息整合到相关页面，保留来源。
- **Query**：基于知识库回答问题；有长期价值的内容经授权后回填。
- **Lint**：检查内容矛盾、过期信息和链接问题，按授权修复。
