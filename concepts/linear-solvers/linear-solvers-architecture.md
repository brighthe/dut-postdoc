# 线性求解器体系架构

> 本页是线性方程组 $\mathbf A\mathbf x=\mathbf b$ 的求解方案选型入口：根据矩阵性质确定适用方法，再结合资源、可用矩阵信息及求解需求筛选方案，最后验证精度与成本。算法原理、方法分类及实现细节分别由 [[direct-methods|直接法]] 和 [[iterative-methods|迭代法]] 维护。

## 1. 求解方案的基本选择

| 方案 | 基本做法 | 选型时关注什么 |
|---|---|---|
| [[direct-methods\|直接法]] | 分解矩阵，再回代求解 | 因子能否存储、分解成本是否可接受，以及能否通过多右端项复用摊薄成本 |
| [[iterative-methods\|迭代法]] | 反复作用算子，逐步改进近似解 | 是否有有效且成本合适的预条件子，以及达到所需精度的总耗时 |

两类方法可以组合，例如多重网格的最粗层可以使用直接法。迭代方案通常还需选择外层方法与预条件子。

## 2. 按问题条件选择方案

### 2.1 根据矩阵性质确定候选方法

按实际施加边界条件后的系统判断矩阵性质，确定适用方法的范围。

| 矩阵性质 | 直接法候选 | 迭代法候选 |
|---|---|---|
| 对称正定（Symmetric Positive Definite, SPD） | Cholesky | 共轭梯度法（Conjugate Gradient, CG），配合预条件成为预条件共轭梯度法（Preconditioned Conjugate Gradient, PCG） |
| 对称不定 | 带适当选主元的 LDLᵀ | 极小残差法（Minimal Residual, MINRES），可配合适的块预条件 |
| 非对称 | 带选主元的 LU | 广义极小残差法（Generalized Minimal Residual, GMRES）、稳定双共轭梯度法（Biconjugate Gradient Stabilized, BiCGSTAB） |


### 2.2 根据计算条件形成候选方案

从 §2.1 的适用方法中，结合可用矩阵信息、网格层次和资源形成可行方案。满足多行条件时，可以保留多个候选，通过 §3 的验证和比较确定最终选择。

| 候选方案 | 需要具备的条件 | 主要比较项 |
|---|---|---|
| 直接法 | 可获得显式矩阵，分解资源可承受 | 填充、分解成本、因子复用 |
| 迭代法 + Jacobi | 可获取对角元，与外层方法兼容 | 迭代次数、作用成本 |
| 迭代法 + 不完全 Cholesky（Incomplete Cholesky, IC）或不完全 LU（Incomplete LU, ILU） | 有显式稀疏矩阵，与外层方法兼容 | 分解成本、填充、三角求解 |
| 迭代法 + 几何多重网格（Geometric Multigrid, GMG） | 有合适的几何层次及层间转移 | 层次构造、收敛与更新成本 |
| 迭代法 + 代数多重网格（Algebraic Multigrid, AMG） | 有显式稀疏矩阵，可构造有效粗空间 | 粗化、收敛与更新成本 |
| 迭代法 + 块预条件或区域分解 | 有适合局部求解的分块或子域结构，与外层方法兼容 | 局部求解、通信及粗空间成本 |

表中条件用于筛选可行方案，不保证收敛速度或总成本最优。具体构造与兼容要求见 [[iterative-methods#3. 预条件子的构造|迭代法 §3]]。若只有算子作用，须确认预条件子所需的对角、几何层次或显式代理矩阵等信息能否另行获取，见 [[../matrix-free/assembly-levels#3. 三条跨层级性质|装配层次的跨层级性质]]；直接法资源估计见 [[direct-methods#2. 填充与排序|直接法 §2]]。

## 3. 选型后的验证

```mermaid
flowchart LR
    A["限定适用方法"] --> B["列出可行方案"]
    B --> C["验证精度与比较成本"]
    C --> D["确定选择"]
```

按 §2.1 限定适用方法，按 §2.2 列出可行方案。在可控规模上核对真残差 $\mathbf r=\mathbf b-\mathbf A\mathbf x$ 及所关心的物理量，必要时用直接法结果对照。真残差小不保证解误差或目标量误差同样小，容差须根据位移、能量、目标函数或灵敏度等实际需求验证。

达到同一精度要求后，再比较目标规模下的收敛表现、峰值内存及总耗时。单次求解应计入分解或预条件子的构造与求解成本；同一矩阵、多右端项场景应比较因子或预条件子复用后的完整批次成本；矩阵频繁变化时，还须计入重新分解、预条件重建或更新的成本，区分可复用结构与需重算的数值数据。复用与代价核算分别见 [[direct-methods#4. 三阶段接口与符号分解复用|直接法 §4]] 和 [[iterative-methods#3.6 代价核算|迭代法 §3.6]]。候选方案未达到要求时，返回 §2 调整。
