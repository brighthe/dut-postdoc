# PIML 局部力学表示选型与近期实测要点

> **核心问题**：面对不同的网络架构与训练方式，怎样根据具体力学问题选择合理模型，避免逐个盲目试错？

## 1. 模型选型的基本思路

单纯从网络调参看，脱离实验很难断言某种架构最优；但结合力学方程与有限元结构，可以通过物理硬约束提前排除不合理的路线：

- **输入形态决定网络类型**：规则子结构网格用 MLP（吞吐最高）；连续坐标/跨网格查询用 DeepONet；非结构拓扑用 GNN。
- **变分极值决定输出接口**：不直接预测刚度矩阵（误差线性且易失真），坚持**预测局部形函数 $\widehat{N}$ 并通过能量内积投影构造刚度**——利用 Ritz 变分极值获得 $\mathcal{O}(\epsilon^2)$ 二阶误差压缩，且天然保证对称正定与刚体模态。
- **能量性质决定训练方式**：线弹性等凸能量问题采用 Data-free 变分损失（免标签）；复杂非线性采用高保真求解器离线监督。
- **求解器与硬件作为底线**：必须保证全局 Krylov 迭代（PCG/GMRES）收敛稳定，且在 GPU 上易于组织为批量矩阵乘法（Batched GEMM）。

## 2. 近期实测结果（基于自主框架与博后面上申报数据）

- **PINN 对照基线**：跑通了 2D/3D 线弹性 PINN。实测表明其作为“求解器”每次迭代均需重训、无离线摊薄，且在材料高对比度界面（$E_{\min}/E_0 \sim 10^{-9}$）误差偏大；证实其不适合直接做拓扑优化求解，但其无标签变分损失很适合用于 PIML 局部形函数的 Data-free 训练。
- **PIML 变分二阶误差压缩**：对比了“预测形函数（路线 A）”与“直接预测刚度（路线 B）”：
  - 形函数自身 $8.97\%$ 的预测误差，经变分能量投影后刚度误差降至 **$0.44\%$**（log-log 拟合斜率 $2.00$）；
  - 24 子结构装配下，路线 A 全场位移误差为 **$0.15\%$**（路线 B 为 $2.01\%$）；
  - GPU 批量缩聚（Batched GEMM）实现 **$22\sim 26$ 倍加速**（$24\sim 384$ 个子结构耗时 $0.23\sim 3.32\text{ ms}$）。
- **Matrix-Free 与 GPU 拓扑优化平台**：
  - 算子与显式装配严格同解（相对差 $<10^{-12}$），3D 实测规模达 159 万自由度（内存节省 3.1 倍）；
  - **160.4 万自由度三维拓扑优化**（Hex8 SIMP）145 步平稳收敛，单步耗时由 85.65 s 降至 2.37 s（**GPU 端到端加速 36.1 倍**，显存仅 2.66 GB）。

## 3. 待讨论议题

1. **局部表示推进路线**：实测显示“变分形函数路线”优势明显，向三维复杂几何拓展时，是否继续以此为主线？
2. **局部误差与无矩阵求解器衔接**：局部近似算子进入 Matrix-Free 迭代时，采用“精确算子复核真残差 + 自适应回退”机制是否可行？
3. **首个合作算例**：双方合作启动的第一项数值实验，选取哪个代表性构件或算例作为基准对照？
