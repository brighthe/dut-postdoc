# 摘要

拓扑优化被广泛用于工程设计，以识别高效传力路径并实现轻量化结构。然而，名义设计（即不考虑失效场景的设计）往往忽略结构鲁棒性，导致冗余度有限并易受局部失效影响。为克服这些局限，失效安全概念已被纳入拓扑优化框架。尽管近期取得了进展，现有研究主要集中于离散系统或二维连续体，而实际工程结构通常是三维且大规模的，需要高分辨率分析。本研究系统考察了大规模三维连续体结构的失效安全拓扑优化。为缓解三维分析带来的巨大计算负担，采用了近期发展的问题无关机器学习（PIML）技术进行加速。代表性数值算例表明，失效安全设计与其名义设计存在显著差异：具体而言，大规模三维连续体的最优拓扑趋向于呈现板壳或箱型特征。这些几何特性降低了局部损伤引发灾难性坍塌的风险，从而显著提升了整体结构完整性与鲁棒性。

# 5 结论

本研究考察了大规模三维连续体结构的失效安全拓扑优化，该领域此前受制于高分辨率分析的高昂计算成本与损伤场景的组合性质。为克服“维数灾难”，我们成功地将问题无关机器学习框架与子结构有限元分析结合。该方法大幅加速了缩聚刚度矩阵与灵敏度的计算，使三维失效安全设计的高效探索成为可能。

系统的数值实验揭示，失效安全要求会在大规模三维连续体中诱发根本性的拓扑转变。与通常收敛到为纯拉伸优化的桁架状或拉杆系统的名义设计不同，失效安全设计一致地演化为板壳或闭孔箱型结构。从力学角度看，这类几何构型对局部损伤不对称性引起的弯矩与扭矩具有更优的抵抗能力。二维失效安全解往往依赖冗余的树状传力路径，而本文结果表明，在三维空间中，结构鲁棒性更有效地通过基于面的冗余（即壳与箱）而非离散构件的分离或复制来实现。

尽管 PIML 带来了加速，工业规模应用的计算需求仍是挑战。未来研究将聚焦两个方向：（1）结合主动集策略或损伤场景筛选（Sun 等 2024）与分层并行化（Herrero-Pérez 与 Picó-Vicente 2024），进一步减少所需分析次数；（2）将框架推广到非线性动态失效机制（Whiteside 等 2025），可能借助等效静载荷方法（Lee 与 Park 2015），以更好地契合损伤常由极端冲击或疲劳事件触发的实际工程场景。
