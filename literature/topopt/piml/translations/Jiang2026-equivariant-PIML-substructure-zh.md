# 摘要

对于材料分布高度非均质的复杂结构，往往需要高分辨率数值离散来捕捉结构细节。求解此类问题时，传统有限元方法（FEM）因需求解大规模全局线性方程组而计算代价高昂。基于子结构的方法可以降低全局系统的维数，但会带来额外的局部求解成本。现有的机器学习增强子结构方法试图用神经网络替代在线缩聚过程以加速计算；然而，这类数据驱动方法固有的近似误差可能导致非物理解，子结构的高维性又进一步加剧了模型训练的难度。针对这些问题，本文提出一种基于立方体子结构对称性的简化学习策略，使模型只需学习形函数的基本分量；进一步通过投影修正严格施加形函数的刚体约束，从而同时提高神经网络（NN）的预测精度与物理一致性。数值算例表明，所提方法能够在经典固体力学问题中保持分析一致性；与现有方法相比，预测误差与分析误差均大幅降低，在对响应敏感的点阵结构优化中表现出更好的稳定性。

**关键词**：子结构分析（Substructural analysis）；问题无关机器学习（Problem-independent machine learning）；对称驱动的特征解耦（Symmetry-driven feature decoupling）；拓扑优化（Topology optimization）；构型化复合材料（Architected composite materials）

# 5 结论

本文提出了一种几何对称增强的轻量神经网络框架，用于加速基于子结构的结构分析与拓扑优化。利用立方体子结构的几何点群对称性，发展了一种新的形函数特征解耦方案。该策略在标准 PIML 方法通用性与效率的基础上，显著压缩了神经网络的输出维数，大幅降低训练成本，同时提高了计算精度与泛化能力。进一步引入基于投影的硬物理约束方案，在不破坏固有几何对称性的前提下严格施加刚体不变性并消除非物理运动模式，从而避开了传统按列分块方法带来的误差放大问题。

数值算例表明，新框架在正向结构分析中具有显著更高的精度；在对对称性破缺高度敏感的复杂梯度点阵结构拓扑优化中表现出特别强的鲁棒性，成功克服了原方法中严重的非物理畸变与次优局部极小。同时，在基于密度的连续体拓扑优化中，该框架生成的优化构型与细网格参考解高度一致，并可方便地推广到不同的子结构边界位移假设。

所提对称驱动解耦的内在灵活性允许在单个子结构内无缝集成混合边界位移假设，为更灵活、自适应的多尺度建模铺平了道路。当前基于对称性的降维依赖于子结构可利用的几何对称性；对于不规则或过渡子结构，基本分量及对应的对称变换需要重新定义。未来工作将把该机器学习框架推广到各类过渡子结构以进一步提高分析精度。此外，鉴于子结构刚度矩阵本身具有类似的等变特性，在所提对称增强框架下直接学习并组装缩聚刚度矩阵是一条极具前景的未来研究路线。
