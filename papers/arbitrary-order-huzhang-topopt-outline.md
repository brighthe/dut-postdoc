# 任意次 Hu–Zhang 混合有限元拓扑优化投稿论文框架

> 本文件是面向 CICP 投稿的决策页，只维护论文定位、主张边界、最小证据和投稿门禁。详细公式与章节正文由 [[papers/arbitrary-order-huzhang-topopt-draft-zh|中文稿]] 维护；博士论文第五章及其旧图、旧表和旧数值只作为历史线索，不能直接作为投稿证据。

## 一、论文定位

### 1.1 中心研究问题

在单纯形网格上，任意次 Hu–Zhang 对称应力混合离散能否形成一套数学一致、可实现且可验证的密度拓扑优化框架；它在不同阶次、复杂边界、近不可压缩材料和局部应力约束中能够提供哪些可靠性、精度与成本权衡？

论文以“问题或缺口 → 方法 → 可核查主张 → 公平比较 → 适用边界”为叙事主线。“任意次”“高精度”“抗闭锁”和“应力可靠”均为待验证能力，不作为预设结论。

### 1.2 CICP 投稿定位

首选目标期刊为 *Communications in Computational Physics*（CICP）。论文以任意次 Hu–Zhang 混合离散及其在密度拓扑优化中的一致计算框架为中心；近不可压缩和局部应力约束是验证方法价值的代表性问题，不与离散方法并列为独立主题。

数学性与计算力学性只决定 CICP 稿件内部的贡献排序：若形成可分析的方法增量，则强化假设、命题和数值分析；若主要证据来自困难力学优化问题，则强化计算模型、公平比较和适用边界。正式证据不足以支撑 CICP 时重新选刊，不通过包装旧结果维持既定目标。

期刊级别、积分和动态目录信息由 `repository:heliangos:career/dlut-postdoc/journal-strategy.md` 维护，本文件不复制。

### 1.3 候选贡献

| ID | 候选贡献 | 表述边界 |
|---|---|---|
| C1 | 将任意次 Hu–Zhang 对称应力元用于单纯形网格上的密度拓扑优化 | 必须经系统文献核查后判断是新方法、方法组合还是工程实现；不把既有有限元构造声明为本文原创 |
| C2 | 统一处理高阶稳定离散、低阶跳量稳定化、角点自由度松弛和非齐次牵引提升 | 既有稳定化和松弛方法只作为面向拓扑优化的一致组合、实现与验证，除非本文提供新的理论结果 |
| C3 | 以近不可压缩和局部应力约束问题验证独立应力离散的价值 | 只报告通过公平成本比较和独立复核的结论；正文至少保留一类证据充分的应用 |

### 1.4 写作与论断边界

- 当前维护中文稿；英文题目、摘要结论和结果讨论在正式证据完成后重写。
- $H(\mathrm{div})$ 协调性只保证内部面法向牵引单值，不表示完整应力张量跨单元连续。
- “无体积锁定”必须受离散稳定性、材料插值和求解精度假设约束；默认只报告所考察参数下的退化情况。
- 表观应力约束只避免特定密度分母型表达，不消除点载荷、尖角、重入角或几何退化造成的连续体应力奇异性。
- 未通过文献边界、公式核查和对应 acceptance 的主张不得进入摘要、贡献列表或结论。

## 三、拟定正文结构

| 正文章节 | 核心任务 |
|---|---|
| 1. 引言 | 界定既有混合拓扑优化与 Hu–Zhang 线弹性工作的交叉缺口，按 C1–C3 组织贡献 |
| 2. 任意次 Hu–Zhang 混合形式 | 给出 Hellinger–Reissner 形式、牵引提升、任意次空间、低阶稳定化和角点松弛的必要定义与边界 |
| 3. 密度法拓扑优化 | 给出互补能柔顺度、材料插值、表观应力约束、ALM/MMA 与一致伴随灵敏度 |

| 5. 结论 | 只总结正式证据支持的能力、失败范围和适用条件，不扩展到三维、非线性或 MMC/MMV 耦合 |

复杂空间构造、完整差分表、参数扫描和次要消融优先放入 Supplementary Material；中文稿可在投稿结构冻结前保留更多推导。

## 四、最小证据与 acceptance

实验权威入口为 `repository:soptx:experiments/huzhang_topopt_paper/README.md`。Legacy driver 和博士论文结果只用于恢复问题定义；投稿证据必须由新的原生入口生成并带 provenance。

### 4.1 最小证据矩阵

| 证据层 | 固定范围 | 主要输出与作用 |
|---|---|---|
| 前向验证 | 博士论文第 5.4.3 节的非零牵引制造解；$k=1,2,3,4$；五档规则三角网格和五档递归加密的非结构三角网格 | 位移/应力误差、$H(\mathrm{div})$ 误差、平衡残差、法向迹跳量、DOF、时间和内存 |
| 边界消融 | 低阶稳定化与复杂角点松弛开/关 | 边界残差、误差、求解状态和失败记录 |
| 灵敏度 | 非零牵引的小规模固定设计 | 柔顺度与应力约束的中心差分误差和步长趋势 |
| 一般柔顺度 | 两端固支梁；Hu–Zhang $k=2,3$；两档网格 | 建立中性基线并比较目标、体积分数、设计和成本 |
| 近不可压缩 | 二维轴承及固定 $\nu$ 序列 | 位移法与 Hu–Zhang $k=2$ 全序列比较；端点增加 $k=3$ |
| 局部应力约束 | 有限宽载荷悬臂梁；两档网格 | 比较体积分数、最大归一化应力、违反量、优化历史和成本 |
| 独立复核 | 冻结全部最终设计并使用统一高阶加密 Hu–Zhang 模型 | 预先固定网格、次数、积分规则与奇异邻域；复核柔顺度、体积分数、应力指标和平衡残差 |

公共 v1 不包含两点载荷夹持板、三维算例和全部 legacy variants；只有核心证据不足时才重新评估扩展。

> **实现对齐状态（2026-08-02）**：正式制造解现固定为博士论文第 5.4.3 节的问题定义。当前 `repository:soptx:experiments/huzhang_topopt_paper/cases.toml#forward-manufactured` 及其原生 executor 仍使用另一套 exponential–sine 精确解，尚未与本页对齐；完成该对齐并重新通过 acceptance 之前，现有运行不得作为本算例的正式投稿证据。

### 4.2 固定 acceptance

- 高阶制造解最后三档网格的观测阶不得低于文献核查确认的理论阶减 $0.35$。
- $k=1,2$ 按核查后的低阶理论标记为 `gate` 或 `characterization`；已知混合边界降阶不套用高阶门槛。
- 相对平衡残差不高于 $10^{-8}$，归一化内部面法向牵引跳量不高于 $10^{-10}$。
- 中心有限差分在最优步长处的相对误差不高于 $10^{-5}$，并检查预期二阶趋势。
- 体积分数误差不高于 $10^{-3}$，应力约束违反量不高于 $3\times10^{-3}$。
- 冻结设计连续两级加密后的柔顺度与最大归一化应力变化均低于 $1\%$，方可作为最终比较证据。
- 所有方法均报告自由度、墙钟时间、峰值内存、线性/优化迭代次数和失败案例。

### 4.3 Evidence 状态

- `historical`：博士论文或 legacy driver 中的旧结果，只能帮助恢复参数。
- `development`：环境、revision 或 acceptance 尚未满足正式证据要求。
- `validated`：公式、配置和 acceptance 通过，但尚未在 clean revision 上形成完整 provenance。
- `formal`：clean revision 上重算，环境、参数、产物与 SHA-256 完整；只有此状态可进入投稿定量结论。

## 五、博士论文第五章复用边界

### 5.1 可作为起点

- Hellinger–Reissner 连续模型、Hu–Zhang 空间及几何分解可以作为重写起点，但须对照原始文献核查。
- 既有低阶稳定化、角点松弛、材料插值和 ALM 公式只作为推导线索，必须与当前记号和实现重新对齐。
- 旧算例可用于恢复几何、边界和参数，不作为比较结果或投稿证据。

### 5.2 禁止直接复用

- $\nu=0.5$ 与 $\nu=0.4999$ 混标的旧图、旧表和旧结论。
- 完整应力张量跨单元连续的表述。
- 无条件的“无体积锁定”结论。
- “彻底消除应力奇异性”的表述。
- 未通过重新推导和差分检查的状态方程及灵敏度公式。
- 仅凭各方法自身应力场得到的优越性结论。

## 六、CICP 投稿门禁

### 门禁 A：理论与文献核查

- 完成 Hu–Zhang 任意次离散、低阶稳定化、角点松弛、truly-mixed 拓扑优化、近不可压缩和应力约束文献核查。
- 将每项内容区分为既有理论、本文实现、候选增量和禁止使用的强主张。
- 完成非齐次牵引、总应力、柔顺度与 ALM 伴随灵敏度的统一推导。
- 请熟悉该工作的专家评审创新性、正文取舍和最小证据范围，并形成可执行结论。

### 门禁 B：正式证据

- `soptx` 原生入口、配置、manifest、summary 和 provenance 协议可执行。
- 公共 v1 全部运行，失败项同样形成可追溯记录。
- 核心比较采用匹配网格、相近自由度或实际成本口径，并通过冻结设计独立复核。
- 只有 clean revision 结果晋级为 `formal`；旧结果和开发结果不进入投稿表格。

### 门禁 C：CICP 适配复核

- 至少一项方法增量在既有 Hu–Zhang 理论与混合拓扑优化工作的交叉处具有清晰新颖性。
- 理论推导、实现验证和代表性物理问题形成闭环，而不是只完成算例迁移。
- 数学叙事必须有可核查的方法或分析增量；计算力学叙事必须有公平成本下的稳健改进及独立复核。
- 门禁通过后创建英文/LaTeX 投稿工程，核验 CICP 最新模板、参考文献元数据以及作者、单位、ORCID、基金和数据声明；未通过时缩减主张、补充证据或重新选刊。
