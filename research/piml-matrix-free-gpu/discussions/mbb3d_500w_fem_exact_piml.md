# 三维 MBB 梁 500 万自由度：全尺度 FEM、精确子结构与 PIML 子结构的对照

硬件：CPU：16 核 32 线程，可用内存 45 GiB；NVIDIA GeForce RTX 5070 Ti，可用显存 16 GB。

软件：Ubuntu 24.04，Python 3.12.13；NumPy 2.5.3，SciPy 1.18.1，PyTorch 2.11.0（CUDA 12.8）。

## 1. 研究对象

三种方法求解同一个拓扑优化问题，差别只在每轮状态分析所用的模型：

| 方法 | 分析模型 | 全局未知量 |
|---|---|---|
| 全尺度 FEM | 在细网格上直接求解全部自由度 | $5\,109\,588$ |
| 精确子结构 | 子结构边界位移由角点三线性插值，内部精确静力缩聚（Schur 补） | $46\,452$ |
| PIML 子结构 | 子结构边界位移由角点三线性插值，内部形函数由网络预测，按变分式缩聚 | $46\,452$ |

## 2. 实验设置

三种方法采用相同的细网格、材料参数、载荷与支承条件，以及拓扑优化参数和线性求解收敛准则。精确子结构与 PIML 子结构采用相同的子结构划分，每个子结构包含 $5\times5\times5$ 个细单元，以保持两者的空间划分与边界插值条件一致。

| 参数 | 取值 |
|---|---|
| 问题 | `FullMBBBeamPoint3d`，顶面中心集中力 $-1$，左端两底角点铰支，右端两底角点 $u_y=u_z=0$ |
| 网格 | 结构化六面体 $390\times65\times65$，$h=1$，$1\,647\,750$ 个单元 |
| 材料 | $E_0=1$，$E_{\min}=10^{-7}$，$\nu=0.3$，修正 SIMP，$q=3$ |
| 离散 | 线性元，二阶高斯积分 |
| 优化 | 体积分数 $0.12$，均匀初值；密度过滤，半径 $3h$；OC，移动限 $0.2$，阻尼 $0.5$ |
| 收敛 | 柔顺度相对变化连续 5 轮小于 $2\times10^{-4}$，最多 300 轮 |
| 线性求解 | CG + Jacobi，相对右端项容差 $10^{-6}$，最多 20000 步，第 2 轮起以上一轮的解为初值 |
| 子结构划分 | $78\times13\times13$ 个子结构，每个 $5\times5\times5$ 个细单元 |

PIML 子结构采用 MLP，以精确内部形函数 $N_i^j$ 为标签进行监督学习，损失为补全后预测形函数与精确形函数的逐元素 MSE。网络在离线阶段训练，在线拓扑优化仅使用训练好的网络进行推理。

| 离线阶段 | 取值 |
|---|---|
| 样本 | 单个子结构（$m=5$，$h=1$，$\nu=0.3$）上逐单元独立均匀采样归一化模量 $\widehat E_e\in[10^{-7},1]$；训练 $400\,000$、验证 $40\,000$；标签为精确 $N_i^j$ 的独立条目 |
| 网络 | 4 个 MLP 子网络并联，输入 125 维、输出 3456 维；每个子网络 15 个隐藏层，宽度 60–200，tanh 与 elu 混合；约 $1.28\times10^6$ 个参数 |
| 训练 | 损失为补全后 $\widehat N_i^j$ 与 $N_i^j$ 的逐元素 MSE；Adam，初始学习率 $10^{-3}$，batch 256，500 轮 |

## 3. 精度对照

下表每行为一份设计，各列为用不同分析模型计算的柔顺度；加粗为该设计在优化中由自身模型给出的 $C_{\mathrm{opt}}$，用全尺度 FEM 计算的一列即 $C_{\mathrm{Fine}}$，设计优劣以它为准。

### 3.1 精确子结构与全尺度 FEM：角点三线性插值的模型误差

| 设计 | 全尺度 FEM | 精确子结构 | 精确子结构相对全尺度 FEM |
|---|---|---|---|
| 全尺度 FEM 优化出的设计 | **$9.422055$** | $6.996437$ | $-25.7\%$ |
| 精确子结构优化出的设计 | $9.869019$ | **$6.974166$** | $-29.3\%$ |

两行的最后一列都为负，同一密度场上 $C_{\mathrm{Exact}}\le C_{\mathrm{FEM}}$。用全尺度 FEM 计算，精确子结构优化出的设计（$9.869019$）比全尺度 FEM 优化出的设计（$9.422055$）高 $4.74\%$，即角点三线性插值带来的设计损失。两份设计的拓扑都是对称的。

## 4. 计算成本

### 4.1 离线阶段：样本生成与网络训练

PIML 子结构在线使用的网络须先离线训练一次，这部分成本与在线优化无关，但属于方法的总成本。两步均在正式规模下计时：样本生成为训练 $400\,000$、验证 $40\,000$ 个样本，生成批量 256；网络训练为 500 轮，batch 256，未触发提前停止。两步均用 PyTorch 后端；CPU 侧 16 线程，GPU 侧主机单线程。样本生成精度 float64；网络训练精度 float32。

| 步骤 | CPU | GPU | CPU / GPU |
|---|---|---|---|
| 样本生成，$440\,000$ 个样本总耗时 | 1498 s（约 25 min） | 57.8 s | 25.9 |
| 网络训练，500 轮总耗时 | 5 h 54 min | 26 min | 13.6 |
| 网络训练，每轮 | 42.4 s | 3.1 s | 13.7 |
| 网络训练，最佳验证损失（最佳轮） | $6.3944\times10^{-6}$（491） | $6.3936\times10^{-6}$（491） | |

1. **样本生成 GPU 快约 26 倍**：$440\,000$ 个样本 CPU 约 25 min，GPU 约 1 min；两侧样本逐元素相同，标签只差浮点舍入。
2. **网络训练 GPU 快约 14 倍**：500 轮 CPU 5 h 54 min，GPU 26 min；两侧终态验证损失相对差 $1.3\times10^{-4}$，为舍入噪声水平。

### 4.2 在线阶段：PIML 子结构的装配与求解

CPU 与 GPU 均用 PyTorch 后端，单进程运行，不用 MPI；CPU 侧 `--threads 16`，用满 16 个物理核，GPU 侧主机为单线程。

| 指标（单位 s） | CPU | GPU | CPU / GPU |
|---|---|---|---|
| 每轮装配，均值 | 12.88 | 1.80 | 7.2 |
| 每轮求解，均值 | 1.11 | 2.16 | 0.51 |
| 每轮恢复，均值 | 0.06 | 0.03 | 1.9 |
| 每轮其他，均值 | 2.28 | 1.88 | — |
| 每轮分析耗时，均值 | 14.05 | 3.99 | 3.5 |
| 整轮，均值 | 16.32 | 5.87 | 2.8 |
| CG 步数，均值 | 2139 | 2136 | — |
| 轮数 / 优化循环总耗时 | 83 / 1355 | 83 / 488 | 2.8 |
| 进程 RSS 峰值 / 显存峰值（GiB） | 9.85 / — | 9.40 / 5.64 | — |

1. **装配 GPU 快 7.2 倍**：装配逐批处理 256 个子结构，局部刚度、网络推理与变分式 $\widehat N^{\mathsf T}K\widehat N$ 都是规整的批量稠密运算，适合 GPU。
2. **求解 GPU 反而慢一倍**：两侧 CG 步数相同，CPU 每步约 0.52 ms，GPU 约 1.01 ms。角点系统只有 $46\,452$ 个未知量，每步计算量很小，角点系统更大时 GPU 才能展现加速效果。
3. **整轮只快 2.8 倍**：GPU 上装配不再是瓶颈，求解与其他一项（主要是在主机上写 VTU）合计占整轮的七成。

**更大规模下的求解**：用 $540\times90\times90$ 档（$4\,374\,000$ 个单元，$13\,440\,063$ 个自由度，角点未知量 $118\,047$）验证第 2 点，取优化前 5 轮的均值。
