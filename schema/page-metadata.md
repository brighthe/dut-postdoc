# 笔记属性说明

说明哪些文档需要笔记属性，以及各字段的用途、填写要求与状态含义。属性保存在 Markdown 文件顶部的 YAML frontmatter 中。

## 适用范围

| 范围 | 需要笔记属性的文档 |
|---|---|
| concepts/ | 概念笔记，包括 inbox/ 中的待分类概念文档 |
| literature/ | 文献译文与文献整理页 |
| papers/ | 自己的论文提纲与正文草稿 |
| entities/ | 人物、软件档案，以及工作汇报、交流和讨论记录 |

按文档用途判断，不要求上述目录中的所有文件都有属性。README.md 等辅助说明、AGENTS.md、schema/ 中的规范文档，以及代码、图件、refs.bib、.gitkeep 不强制添加笔记属性。

research/、funding/、archive/ 暂不列入强制范围；已有属性保留，不批量删除。现有索引可继续使用其已有属性。

## 通用字段

| 字段 | 要求 | 含义与写法 |
|---|---|---|
| title | 必填 | 笔记标题，填写真实名称 |
| tags | 必填 | 主题标签，使用列表 |
| status | 必填 | 文档完成或核验状态，按文档类型取值，见下文 |
| date_added | 必填 | 笔记创建日期，不是原始资料发表日期 |
| date_update | 必填 | 最近一次实质修改日期 |
| type | 建议填写 | 文档类型，如 concept、translation、paper、entity、report、discussion；按文档用途填写，不直接套用目录名 |
| aliases | 可选 | 别名、英文名称或缩写，使用列表，供检索与链接使用 |
| source | 按需填写 | 整篇笔记主要依据的来源，单一来源可用字符串，多个来源用列表；具体结论的引用仍放正文 |

日期使用 YYYY-MM-DD。未知事实明确标“待确认”，不保留占位符；不适用的可选字段可省略，有明确含义的空列表可以保留。必填日期不得猜测，既有字段的处理见“现有属性与兼容”。

## 专用字段

| 文档类型 | 字段 | 要求与用途 |
|---|---|---|
| 概念笔记 | 无额外必填字段 | 通用字段即可，参考依据放正文 |
| 文献译文 | source | 必填，使用指向原始 PDF 的相对路径双链；YAML 中用引号包裹，如 `"[[../sources/<basename>.pdf]]"`，以便在 Obsidian 属性中跳转 |
| 文献译文 | citekey | 可选；填写时须与 literature/refs.bib 中的 Citation Key 一致 |
| 文献译文 | language | 必填，译文语言，如 zh-CN |
| 自己的论文 | authors | 作者确定后填写，按署名顺序使用列表，不臆造作者或顺序 |
| 自己的论文 | target_journal | 可选，当前拟投期刊 |
| 人物／软件档案 | entity_kind | 必填，区分 person、software 等对象；汇报和交流页不因位于 entities/ 而必填此字段 |
| 工作汇报／交流记录 | 无额外必填字段 | 多次交流的日期、对象与结论放正文，避免用一组页面属性描述多次事件 |

文献作者、DOI、期刊和发表年份等出版信息由 refs.bib 与文献页面的信息区承载，不要求全部重复写入笔记属性。译文的内容、格式与核验要求另见 [[translation]]。

## 状态含义

| 文档类型 | 状态与含义 |
|---|---|
| 概念、实体档案、文献整理与讨论记录 | draft：初稿；in-progress：维护中；done：本页内容已完成，不表示全部结论都已独立验证 |
| 译文 | draft：未完成；read：内容已整理、未完成逐页核验；done：已对照原始 PDF 完成逐页核验，核验范围见 [[translation]] |
| 工作汇报 | preparing：准备中；reported：已实际汇报；follow-up-done：后续行动已完成 |
| 自己的论文 | outline：提纲；drafting：正文初稿 |

暂存于 concepts/inbox/ 只表示分类待定，不替代完成或核验状态。文档状态描述当前笔记或稿件，不自动代表研究项目进度、投稿结果或来源真实性。

## 现有属性与兼容

- 本规范用于新建笔记和后续按需维护，不据此批量补齐、删除或重命名现有文档的属性。
- 现有译文的 date_created、date_updated 继续保留，分别表示该笔记的创建与更新日期；不同时新增含义重复的日期字段。
- 部分旧页面使用 date_start，先保留原有含义，不自动等同于笔记创建日期；统一前需核实字段含义与日期，并另行确认迁移范围。
- 已有索引、指南或研究计划的 draft、in-progress、done 等状态，以及归档页的 archived 状态可沿用；索引状态描述索引自身，归档页已有事件日期和归档日期保留，不据此扩大强制适用范围。
