# 译文要求

笔记属性与状态见 [[page-metadata]]。

## 文件与来源

- 原文使用 AuthorYear-short-topic basename，中文译文加 -zh。
- literature/refs.bib 中新文献的 Citation Key 使用 basename，既有 key 保留；译文属性中的 citekey 可省略，填写时须与该条目一致。
- 原始 PDF 是翻译与核验依据，提取文本仅作辅助。

## 内容与格式

- 保留原文章节、编号、公式、图表、附录与参考文献，不自行增删内容。
- 正文包含论文信息、摘要及原文各节；出版信息按原文记录，缺失或未核实内容明确标注，区分预印本与正式发表版本。
- 术语、作者姓名和引用忠实原文；疑似错误用译者脚注说明，不静默改正。
- 公式使用 LaTeX；图题在图下、表题在表上。图件存放于主题 assets/，按 AuthorYear_Fig编号.png 命名，以裸文件名嵌入。

## 核验与交付

- 对照原始 PDF 核查全文，覆盖章节、公式、图表、脚注、参考文献与来源；出版信息与 refs.bib 核对，译文属性中填写了 citekey 时一并核对。
- 只有完成逐页核验才能标记 done；部分核验应如实说明范围与未解决问题，语法检查不能替代原页核验。
