## 研究定位与投稿边界

研究目标是利用可复用的学习局部算子，结合 Matrix-Free 求解和 GPU 执行，降低大规模拓扑优化中结构分析的时间与存储成本。专题按这一目标定位，摘要结论则必须按实际完成的证据收束。

2026-09-07 读取研究计划（文件更新日期 2026-09-04）时，已有阶段结果包括 PIML 结构分析、角点线性迹 PIML 的二维／三维优化闭环、小规模 PIML–Matrix-Free 算子恒等验证和独立 GPU 求解基线；GPU 融合全链、精确算子真残差复核及融合优化闭环尚未完成。此处是投稿讨论的历史快照，后续状态直接查看研究计划。

## 投稿前需核实的证据

- 区分 CPU 显式 PIML 优化闭环、精确 Matrix-Free/GPU 基线与三线融合结果；只有融合全链完成后才能声称全程显存驻留。
- 3.02% 和 3.65% 的比较对象是角点线性迹子结构缩聚基线，不能等同于普通全装配有限元基线；需复核修复后统一工况下的可重放结果。
- 形函数预测与变分构造有既有文献来源，说明项目新增贡献与已有方法的边界；“已有路线均未利用学习近似”等文献判断需专项核查。
- 区分二阶误差恒等式的适用条件与 log-log 斜率 2.00 的数值证据，不能仅由拟合斜率断言普遍严格二阶性质。
- 若报告融合性能，补齐预测、局部作用、归约、Krylov 的设备驻留证据、精确参考算子真残差和迭代数比较。
- 区分按每自由度字节数外推的容量上限与实测可解规模；统计局部算子、向量、临时缓冲及预条件的峰值存储。
- 在统一算例和停止准则下完成逐层消融；记录 CPU 线程／进程、GPU、精度及完整计时范围，分别报告单线程与受控并行基线。
- 统一摘要开头、结果段和结尾的完成状态，删除未填占位符；未完成内容使用研究计划措辞，不写为数值结论。

上述清单只约束本次投稿的证据选择，不授权启动实验。会议报告完成后，按 talks 约定提取长期知识并将本目录整体归档。
