# CCCM2026 投稿摘要草稿

> 本稿按研究及完整拓扑优化验证均已完成的情形撰写，用于确定本次投稿的叙事与结果组织，不代表当前实现状态。数值占位符须在正式投稿前替换为核实后的结果。专题选择见 [[README]]，实际研究进度见 [[../../research/piml-matrix-free-gpu/project-plan|研究计划]]。

## 投稿信息

- 拟投专题：MS13 高性能计算力学
- 报告形式：口头报告（拟）

## 题目

面向大规模结构拓扑优化的 PIML–Matrix-Free 方法与 GPU 加速

## 摘要

大规模结构拓扑优化需要在密度演化过程中反复求解平衡方程，其计算成本受到局部力学算子构造、全局矩阵存储及线性系统求解的共同制约。本文提出一种融合问题无关机器学习（PIML）、Matrix-Free 求解与 GPU 并行执行的结构拓扑优化方法，同时降低重复分析成本与全局矩阵存储需求。

该方法以子结构密度场为输入预测多尺度形函数，经变分构造获得满足对称性、半正定性及刚体模态约束的局部力学算子；通过局部自由度提取、算子作用与贡献累加实现全局 Matrix-Free 运算，并采用 Krylov 方法求解平衡方程。在此基础上，将局部算子更新、位移恢复、灵敏度计算、滤波与设计变量更新接入完整拓扑优化流程，在 GPU 上执行，并引入子结构层精确回退机制控制拓扑演化中的代理误差。

以二维和三维 MBB 梁为例，在统一离散、接口迹空间与收敛准则下，对精确算子与学习算子、显式组装与 Matrix-Free 路径进行逐层对照。结果表明，相对相同接口迹下的精确缩聚基线，所提方法的最终柔度偏差不超过【ε】%，满足给定体积约束，并获得相近的优化拓扑。对于【N】自由度的三维算例，完整优化耗时降低【t】%，峰值显存减少【s】%；在同一 GPU 的显存约束下，实测可解规模达到【M】自由度，为显式组装基线的【k】倍。精确参考算子下的残差与优化历史对比进一步验证了融合方法的求解精度及优化稳定性。

该方法将可复用的学习局部表示与免组装计算相结合，为有限显存条件下的大规模结构拓扑优化提供了一条有效途径。
